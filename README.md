# MotiThera

DTC Shopify project for the MotiThera Photobiomodulation Cervical Drape — a dual-wavelength (660nm red + 850nm NIR) light-therapy wearable targeting chronic neck/trap tension and cervicogenic headaches in desk workers.

Start with [`CLAUDE.md`](CLAUDE.md) for standing rules, store access, and current status — that file is the source of truth for how Claude Code should operate on this project.
