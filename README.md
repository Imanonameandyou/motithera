# MotiThera

DTC Shopify project for MotiThera Neck Relax — a wearable neck massager (heat, vibration massage, low-frequency pulse modes, soft red light) targeting chronic neck/trap tension in desk workers. The original offer brief was written around a clinical dual-wavelength (660nm/850nm) photobiomodulation device; the actual sourced unit (see `sourcing/`) doesn't have those specs verified, so product copy is written to the real spec sheet — see `CLAUDE.md` → "Claim integrity."

Start with [`CLAUDE.md`](CLAUDE.md) for standing rules, store access, and current status — that file is the source of truth for how Claude Code should operate on this project.
